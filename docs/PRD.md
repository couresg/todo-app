# 할 일 관리 앱 PRD

## 1. Why - 목적
- 일일 할 일과 장기 목표가 따로 노는 문제 해결
- 할 일 → 주간 계획 → 1년 목표 계층으로 실행을 목표에 연결
- 주간 진행률 자동 계산으로 수동 진척 관리 제거

## 2. Who - 타깃 사용자
- 1년 목표를 세우고 주 단위로 계획·실행하는 개인 사용자
- 일일 할 일을 상태별(todo/doing/done)로 관리하려는 사용자

## 3. User Flow
1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 일일 할 일 생성 → 주간 계획에 연결
4. 보드에서 상태별 컬럼(todo/doing/done) 확인
5. 드래그 앤 드롭으로 할 일 상태 변경
6. 상태 변경 시 주간 진행률 자동 갱신
7. 할 일 수정/삭제 → 주간 진행률 재계산

## 4. 기능 요구 사항

### P0 - 핵심 기능
- **할 일 CRUD**
  - 생성: 제목, 날짜, 연결할 주간 계획
  - 조회: 일자별 목록, 상태별 보드
  - 수정: 제목, 날짜, 상태, 연결할 주간 계획
  - 삭제: 단건 삭제
- **상태 관리**
  - 상태값: `todo` / `doing` / `done`
  - 생성 시 기본값: `todo`
- **드래그 앤 드롭 상태 변경**
  - 상태 컬럼 사이로 옮기면 해당 상태로 변경
  - 변경 즉시 저장
  - 저장 실패 시 원래 컬럼으로 되돌림
- **기간 구조**
  - 일일: 할 일 (날짜 단위)
  - 주간: 주간 계획 (주 시작일~종료일)
  - 1년: 목표 (연도 단위)
  - 주간 계획, 1년 목표 각각 CRUD
- **구조 연결**
  - 할 일 → 주간 계획 (N:1)
  - 주간 계획 → 1년 목표 (N:1)
  - 연결 대상 선택: 생성·수정 시
  - 상위 항목 삭제 시: 하위 항목의 연결만 해제 (하위 항목 자체는 유지)
- **주간 진행률 자동 반영**
  - 산식: `done` 할 일 수 ÷ 연결된 전체 할 일 수 × 100
  - 재계산 시점: 할 일 생성, 삭제, 상태 변경, 연결 변경
  - 연결된 할 일이 0개면 0%

### P1 - 추가 기능
- 1년 목표 진행률: 연결된 주간 계획 진행률의 평균
- 진행률 시각화: 주간 계획·1년 목표에 진행 바 표시
- 같은 컬럼 안에서 드래그 앤 드롭으로 순서 변경
- 주간 계획에 연결되지 않은 할 일만 따로 모아 보기
